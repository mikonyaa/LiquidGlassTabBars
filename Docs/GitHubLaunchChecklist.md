# GitHub launch checklist

## Repository

- [x] Name: `LiquidGlassTabBars`.
- [x] Description explains the reusable package, demo, and fallbacks.
- [x] MIT license is included.
- [x] Default branch is `main`.
- [x] CI tests the package and builds the demo.
- [x] Topics cover SwiftUI, iOS, Liquid Glass, accessibility, and templates.

## Presentation

- [x] Root README starts with one real simulator GIF.
- [x] Three tab bar variants have consistent screenshots.
- [x] Image dimensions and filenames are consistent.
- [x] No claim implies Apple affiliation.

## Release

- [x] Tag `1.0.0` only after package tests and the demo build pass.
- [x] Release notes list supported OS versions and fallbacks.
- [x] Known limitations are explicit in the documentation.

## Launch copy

Keep launch posts factual:

> Liquid Glass Tab Bars is an open-source SwiftUI package with three reusable tab bar patterns: native iOS 26, floating glass, and morphing glass. The repository includes a runnable Xcode demo, iOS 17–25 fallbacks, tests, accessibility support, and beginner documentation.

Avoid announcing unfinished templates as if they already exist.
