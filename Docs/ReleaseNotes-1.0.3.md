# LiquidGlassTabBars 1.0.3

`1.0.3` makes package integration unambiguous and broadens behavioral and accessibility verification.

- The repository root is now the only Swift Package manifest and the demo resolves that exact package.
- Selection and reselection behavior is covered directly.
- Both custom variants are rendered with two, three, and five items in tests.
- Reduce Motion, Reduce Transparency, and accessibility Dynamic Type policies are verified.
- Documentation now directs larger destination sets to the system `TabView` wrapper.
- Package and demo version metadata are aligned with `1.0.3`.

The `LiquidUI` product and existing public component API remain unchanged.
