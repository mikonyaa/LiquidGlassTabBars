# Roadmap

The roadmap is directional. Small, finished releases take priority over a large unfinished component catalog.

## v1.0 — Liquid tab bars

- [x] Root repository and Swift Package manifests.
- [x] Native System tab bar example.
- [x] Floating custom tab bar.
- [x] Morphing custom tab bar.
- [x] Configurable themes and accessibility fallbacks.
- [x] Runnable Xcode demo.
- [x] Beginner documentation and AI learning prompt.
- [x] Simulator screenshots and final GIF.
- [x] CI verification on the release Xcode version.

## Possible follow-ups

- Floating action menu.
- Search control and search tab patterns.
- Compact toolbar group.
- Scroll-edge examples.
- iPad layout review.

Broader app templates live as independent repositories in the [Apple Design Templates](https://github.com/mikonyaa/Apple-Design-Templates) collection.
